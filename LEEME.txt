INTEGRATEL PERÚ – PANEL DE INTELIGENCIA FINANCIERA Y CONCURSAL
Versión actualizada con mejoras de presentación y navegación

CONTENIDO
- app.py: aplicación Streamlit.
- requirements.txt: dependencias de Python.
- Movistar_Proceso_Concursal_Reestructuracion.xlsx: libro de datos utilizado por la aplicación.
- Informe_Concursal_Integratel.pdf: informe de referencia actualizado.
- assets/movistar_logo.png: recurso gráfico del encabezado.
- .streamlit/config.toml: configuración visual de Streamlit.

INSTALACIÓN EN WINDOWS (Visual Studio Code)
1. Descomprime el ZIP en una carpeta.
2. Abre esa carpeta en Visual Studio Code (Archivo > Abrir carpeta).
3. Abre Terminal > Nueva terminal.
4. Comprueba que la terminal esté en la carpeta que contiene app.py y requirements.txt.
5. Ejecuta:
   py -m pip install -r requirements.txt
6. Ejecuta:
   py -m streamlit run app.py
7. Abre http://localhost:8501 si el navegador no se abre automáticamente.

CAMBIOS DE ESTA VERSIÓN
- Encabezado con texto blanco y contraste reforzado sobre fondo azul.
- Paleta visual alineada con Movistar: celeste, azul y verde limón.
- Ruta concursal convertida en línea de tiempo vertical con fechas, estados, descripción y base legal.
- Fechas y etapas futuras identificadas como proyecciones, no como hechos confirmados.
- Estados financieros con filtros más claros, jerarquía visual, importes formateados y lectura más ordenada.
- Tablas con encabezados diferenciados, filas alternadas, mejor espaciado y presentación uniforme.
- Limpieza de columnas totalmente vacías y reemplazo de valores None/NaN por guiones cuando corresponde.
- Conservación de los valores cero y de los datos originales del Excel.
- Importes y porcentajes presentados con formatos más legibles.

CRITERIO DE INFORMACIÓN
La aplicación utiliza el Excel incluido y el informe PDF actualizado. Las cifras estimadas, supuestos, cálculos y proyecciones siguen identificándose como tales. Los escenarios de Junta y reestructuración no deben presentarse como decisiones efectivamente adoptadas. Verifica el expediente y las fuentes oficiales antes de actualizar el estado procesal.
